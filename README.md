# Стратегическая сессия – лендинг Алексея Урванцева (классическая версия)

Вторая версия сайта: общий угол «стратегическая сессия для руководящей команды», без антикризисной рамки. Первая версия («Антикризисный штаб») лежит в отдельном репозитории.

Статический сайт без сборки: открывается двойным кликом по `index.html`, публикуется на GitHub Pages. Настройки (`FORM_ENDPOINT`, `YM_ID`, `VK_PIXEL_ID`, `POLICY_URL`, `REQS_URL`) – в начале `js/main.js`, объект `CONFIG`; описание полей такое же, как в первой версии.

## Заголовки для теста

`?h=a` – «Идеи на сессии были, а через месяц ничего не изменилось»; `?h=b` – «…на которой первое лицо говорит последним»; без параметра – основной. Значение уходит в заявку как `headline_variant`.

## Версия для Тильды

`tilda-html-block.html` – весь сайт одним блоком T123 (HTML). Картинки подключаются с адреса GitHub Pages, поэтому сначала публикуется репозиторий.

## Что подтвердить с Алексеем

1. **Блок «Какие задачи решает сессия»** написан по его брифу (ассортимент, каналы продаж, сегментация, клиенты) и кейсу «Лаконд» (приоритеты на 2025–2027). Пункты «Выход из тупика» и «Единое понимание в команде» – мои формулировки по смыслу диагностики и мозгового штурма; нужно подтверждение, что это те задачи, с которыми он работает.
2. **Три места, где ломается сессия** собраны из ответов его FAQ (состав групп, первое лицо говорит последним, план внедрения на сессии). Формулировка «внутри компании любая позиция читается как борьба за ресурс или за место» раньше стояла в контексте кризиса; здесь она применена к любой сессии.
3. Остальные вопросы (цены, логотипы и письма клиентов, регалии, согласие на обработку данных, cookie-баннер) – как в первой версии.
